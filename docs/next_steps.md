# Next steps

The first useful cut is a desk: sign in, pick a folder, write, see the work, Stop, start a new page without leaving the folder, and find that thread again tomorrow. The composer is the product. What comes next should make writing easier — not turn the window into an editor.

## Done here

**A new conversation, same folder.** New parks the day. Earlier brings it back. A send after New is a new agent.

## Do this next

**Keep writing while a reply is coming.**

The box goes still until Cursor finishes. A desk does not take the pen away. You should be able to draft the next note — and send it when the turn settles, or queue it.

## After that

These are the next honest holes, in order. None of them is an IDE.

1. **Copy what arrived.** Selecting text is why this window exists. A reply and a work line should be easy to copy — the command, the file name, the whole bubble — without fighting the page.
2. **Open a work line a little.** A command you can copy. A file name you can reveal. Not a diff viewer. Large diffs still belong in the project.

## Later, if the desk is already a habit

- Pick a model in Settings. The host is pinned to `composer-2.5`.
- Ship the window (`tauri build`, a `.desktop` file) so it is not a dev loop.
- See that you are on a Cursor plan, without bringing billing into the header.

## Not next

A file tree, a diff pane, tabs, themes, or anything that makes this feel like a small IDE. The rest of the window exists so writing has somewhere to go.
